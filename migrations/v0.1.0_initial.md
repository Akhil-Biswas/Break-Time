## Users Table

| Column | Data Type | Constraints | Notes |
|--------|-----------|-------------|-------|
| `id` | `INT` | `AUTO_INCREMENT`, `PRIMARY KEY` | Unique identifier |
| `f_name` | `VARCHAR(50)` | `NOT NULL` | First name |
| `m_name` | `VARCHAR(50)` | `NULL` | Middle name (optional) |
| `l_name` | `VARCHAR(50)` | `NOT NULL` | Last name |
| `email` | `VARCHAR(150)` | `NOT NULL`, `UNIQUE` | Login identifier |
| `password_hash` | `VARCHAR(255)` | `NOT NULL` | Never store plain text passwords |
| `phone` | `VARCHAR(20)` | `NOT NULL` | Store as text to support leading `0` and country codes |
| `photo` | `VARCHAR(255)` | `NULL` | Stores image file path or URL |
| `address` | `VARCHAR(255)` | `NULL` | User address |
| `role_id` | `INT` | `NOT NULL`, `FOREIGN KEY` → `roles(id)` | User role  Foreign Key →[`roles.id`](#roles-table) |
| `is_active` | `BOOLEAN` | `NOT NULL`, `DEFAULT TRUE` | Used to enable/disable accounts |
| `created_at` | `DATETIME` | `NOT NULL`, `DEFAULT CURRENT_TIMESTAMP` | Record creation time |
| `updated_at` | `DATETIME` | `NOT NULL`, `DEFAULT CURRENT_TIMESTAMP`, `ON UPDATE CURRENT_TIMESTAMP` | Auto-updated when record changes |
| `deleted_at` | `DATETIME` | `NULL` | Soft delete timestamp |

## Student Details Table 

| Column | Data Type | Constraints | Notes |
|--------|-----------|-------------|-------|
| `user_id` | `INT` | `PRIMARY KEY`, `FOREIGN KEY` → `users(id)` | References [`users.id`](#users-table); Also the primary key (1-to-1 with `users`) |
| `roll_number` | `VARCHAR(50)` | `NOT NULL`,`UNIQUE` | Text, since rolls can contain letters (e.g., "21CSE045") |
| `department_id` | `INT` | `FOREIGN KEY` → `departments(id)` | References [`departments.id`](#departments-table) |
| `semester`| `TINYINT` | `NOT NULL, CHECK (semester BETWEEN 1 AND 8)`| |
| `section_id` | `INT` | `FOREIGN KEY` → `sections(id)` | References [`sections.id`](#sections-table) |
| `is_cr` | `BOOLEAN` | `DEFAULT FALSE` | Indicates whether the student is a Class Representative (CR) |
| `gender_id` | `INT` | `FOREIGN KEY` → `genders(gender_id)` | References [`genders.id`](#genders-table) |
